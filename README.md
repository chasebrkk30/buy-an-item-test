This project is my 4th python project and first one with user input. When ran, it asks for a name, item you want to buy, quantity of item, price you are willing to pay. 

It takes this subtotal cost and runs it through a VIP discount, prices above 50 have various discount %'s (10-20%)

Then, it multiplies the subtotal cost with the vip discount and creates your discounted amount.

The subtotal cost minus the discount amount makes the total cost.

This project tests my information on nested if's, variables, nested f's, arithmetic, user input, float/integers, code structure, etc.
